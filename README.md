## 📖 À propos

**Créateur de CV & Lettre Pro** est une application web qui permet à n'importe qui de créer un CV professionnel et une lettre de motivation **sans logiciel, sans inscription, et sans payer**.

Tout se passe **dans le navigateur** : l'utilisateur remplit un formulaire, voit son CV se construire en temps réel, puis l'exporte en **PDF**, **PNG** ou l'imprime directement.

---

## ✨ Fonctionnalités

### 📝 Édition
- **Curriculum Vitae** et **Lettre de motivation** dans la même application
- **Aperçu en temps réel** — le CV se met à jour pendant la saisie
- **Exemple pré-rempli** pour comprendre la structure
- **Bouton "Tout effacer"** pour repartir de zéro

### 👤 Contenu du CV
- **Informations personnelles** : nom, poste, email, téléphone, adresse, site web/LinkedIn
- **Photo optionnelle** (upload + suppression)
- **Profil / Accroche** (3-4 lignes)
- **Expériences professionnelles** — ajout/suppression illimité
- **Formations** — ajout/suppression illimité
- **Compétences** — liste dynamique
- **Langues** — avec niveaux
- **Centres d'intérêt** — liste libre

### 🎨 Personnalisation
- **Choix du modèle** de CV
- **Zoom** (ajuster la taille d'affichage)
- **Thème clair / sombre**
- **Réinitialiser** le style

### 💾 Sauvegarde & Export
- **Sauvegarder** le CV (localStorage)
- **Charger** un CV sauvegardé
- **Export PDF**
- **Export PNG**
- **Impression** directe
